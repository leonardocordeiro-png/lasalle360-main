🔧 Configurar Gmail API - La Salle 360

Vamos obter o Refresh Token manualmente

📋 PASSO 1: Configurar Google Cloud Console

Primeiro, configure o redirect URI no Google Cloud:

  1. Acesse: Google Cloud Console
  2. Vá para: APIs & Services → Credentials
  3. Encontre seu OAuth 2.0 Client ID e clique em Edit
  4. Em Authorized redirect URIs, adicione:
http://localhost:8080/oauth/callback

Clique em Save no final da página.

🔐 PASSO 2: Obter Código de Autorização

Clique no link abaixo para autorizar o acesso:

🔐 Autorizar Acesso ao Gmail

⚠️ Importante:

  • Use apenas o e-mail: leonardo.cordeiro@lasalle.org.br
  • Após autorizar, você será redirecionado para uma página de erro (isso é normal)
  • Copie o código da URL (veja explicação abaixo)

🔑 PASSO 3: Obter Refresh Token Manualmente

Como não temos um servidor, vamos usar o método manual:

  1. Após clicar em "Autorizar", você será redirecionado para uma página de erro
  2. Na barra de endereço do navegador, copie o código que aparece após ?code=
  3. Cole o código no campo abaixo e clique em "Gerar Token"

⚙️ PASSO 4: Configurar no Supabase

  1. Vá para: Painel Supabase
  2. Settings → Edge Functions
  3. Adicione variável de ambiente:
  4. Nome: GMAIL_REFRESH_TOKEN
  5. Valor: [cole o refresh token gerado]

🧪 PASSO 5: Testar Integração

  1. Após configurar o token, clique no botão abaixo
  2. Verifique se recebeu o e-mail de teste
  3. Se funcionou, o sistema está pronto!
